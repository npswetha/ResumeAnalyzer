# ResumeFit – AI Resume Analyzer

ResumeFit is an AI-powered web application that analyzes a resume against a job description and provides a compatibility score with actionable feedback.

## Features

* Upload resume in PDF format
* Enter job description
* AI-powered resume analysis
* Resume-job compatibility score
* Matching and missing skills
* Resume improvement suggestions

### Tech Stack
**Frontend:** React.js, Tailwind CSS, Axios
**Backend:** Python, Flask
**AI:** Google Gemini API
**PDF Processing:** PyMuPDF

### AI Model & API
* **AI Model:** Google Gemini
* **API:** Gemini API
* **API Key:** Generated using Google AI Studio
* The Gemini API is used to analyze the resume content and compare it with the provided job description.
